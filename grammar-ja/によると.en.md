# によると

## Meaning

### Matching scope

This rule requires the reviewed attachment and marker morphology. Context is observed token evidence, not a reconstructed full argument or clause. The primary path requires connecting-particle と. A narrow case-particle path requires an observed source cue (報道, 予報, 調査 or 発表) and immediate nominal reported content. Reviewed causal/quoted によると readings remain excluded. This morphological distinction is conservative and does not resolve every possible report.

Form evidence is tentative. Surrounding context determines the intended sense, and unlisted spellings or endings need separate review. Punctuation and blank paragraphs cannot join attachment and marker. Compare the externally resolved explanations below for the source meanings.
